# 桌面版与 Android 版

下载包包含固定版本的中英文技术文档。你可以输入自己的问题，在本机检索并核对
原文，无需 API Key、模型下载或联网。桌面版联网时可以通过“原文”链接访问上游
网站；Android 只允许应用内部导航，外部链接不会打开，但结果内可阅读已保存的
原始片段。

桌面版启动已有的本地 API，并在浏览器中打开界面。启动页提供“退出程序”按钮：
仅关闭检索标签页不会停止服务。评测报告保存在操作系统的用户数据目录，与安装包
分开；安装资源可以保持只读，启动也不依赖当前工作目录。

Android 版是离线证据查看器。每次输入新问题后，手机都会实时计算 BM25、TF-IDF
及倒数排名融合。它使用与桌面基线相同的文档分块、拟合索引参数和开发集拒答阈值。
导出的索引保存语料统计和原文，不保存“问题—答案”对照表，也不会记录你的检索
问题或结果。

手机端不运行完整的 Python 评测 CLI，也不包含可选的 CrossEncoder。健康检查和
回答元数据会明确标注 `portable-index-v1`：这是独立的便携实现，不表示 APK
内运行着 scikit-learn。完整评测保留在桌面或源码版。语义重排实验需要源码安装的
`semantic` 额外依赖与模型下载，常规桌面下载包同样不包含这个模型。

回归测试覆盖所有固定开发集和测试集问题，以及额外的中英文、混合文字、重复词
和词表外问题。逐项比较三种检索器的前 10 条排序和分数，再核对回答或拒答状态、
证据 ID 与引用。浮点分数允许 `1e-12` 相对误差和 `1e-14` 绝对误差；与导出阈值
的差异落在这个范围内时，视为与阈值相等。这个检查能发现这些输入上的回归，
不等于证明任意问题的回答都在语义上正确。

APK 包含文档快照及许可证，不包含固定评测问题。桌面资源另含评测 API 所需的
用例。打包过程不会收入开发者的报告、未追踪语料文件、虚拟环境或私人设置。

运行 `uv run python distribution/prepare_android.py` 可准备公开资源。该步骤需要
共享的 `distribution/portable_host.py`，输出位于 Android 项目的生成目录；桌面
打包也使用同一个资源导出器。构建元数据记录源码 revision，便于复查。

首批跨平台包作为预发布版提供，仍待实体设备测试和发布者证书。每次发布记录实际
通过的可执行文件与模拟器检查，不把这些检查当成已经完成签名或真机认证。
